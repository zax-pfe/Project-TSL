# Project TSL Gobelins

## About

A browser-based 3D game featuring a character on a platform with lasers. The project explores interactive gameplay and custom visual effects using Three.js and TSL.

## Technologies

- **Vanilla JavaScript** for the game logic, without a frontend framework.
- **Vite** for the development server and production builds.
- **Three.js** for the 3D scene and rendering.
- **TSL (Three.js Shading Language)** for writing custom shaders in JavaScript.

## Setup
Download [Node.js](https://nodejs.org/en/download/).
Run the following commands:

``` bash
# Install dependencies (only the first time)
npm install

# Run the local server
npm run dev

# Build for production in the dist/ directory
npm run build
```
